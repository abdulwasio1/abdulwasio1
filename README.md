## 🔭 Currently Working On

### 🚗 [SmartRoute](https://github.com/abdulwasio1/SmartRoute)

An intelligent route-planning application for electric and fuel-powered vehicles.

**What I'm building:**
- Vehicle range and fuel/battery calculations.
- Route planning with distance and travel-time information.
- Charging station discovery for electric vehicles.
- Backend REST APIs using Spring Boot.
- Database management with MySQL.
- Integration with external mapping and charging-station APIs.

**Tech Stack:** Java · Spring Boot · MySQL · Maven · REST APIs
